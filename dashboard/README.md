# 콜린알포세레이트 2024 상병별 청구 대시보드

심평원 공개 웹통계 `성분의 상병별` 화면에서 콜린알포세레이트 5개 성분코드의 2024년 건강보험·조제기준 상위 100상병 자료를 수집해 보여준다.

## 재빌드

```bash
env/bin/python -m src.ingest.hira_web_choline --years 2024 --codes 138101ACH 138101ACS 138101ATB 138103ASY 138104ASY
env/bin/python -m dashboard.build_data
```

## 현재 데이터

- 보험자구분: 건강보험 `4`
- 기준: 조제기준 `201`
- 범위: 2024년 1월~12월
- 행수: 5,376행
- 청구금액: 361,899,720,738원

상병코드는 심평원 웹통계 표기 그대로 `AI10`처럼 저장한다. 기사 작성 시에는 `I10`처럼 ICD-10 표준 코드로 변환해 설명한다.
